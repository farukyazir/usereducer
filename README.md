# 📝 React Todo List App

A simple and interactive Todo List application built using **React.js**. This project helps users manage daily tasks by adding, editing, deleting, updating task status, and filtering tasks based on completion status.

## 🚀 Features

- ➕ **Add Tasks** – Create new tasks with a name and description.
- ✏️ **Edit Tasks** – Update existing task details.
- 🗑️ **Delete Tasks** – Remove tasks from the list.
- ✅ **Update Task Status** – Mark tasks as Completed or Not Completed.
- 🔍 **Filter Tasks** – Filter tasks by All, Completed, or Not Completed.
- ⚛️ **React useReducer** – Manage todo and filter state using a reducer.
- 📱 **Responsive Design** – Clean interface for different screen sizes.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Hooks (`useReducer`, `useState`)

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL** displayed in your terminal, usually `http://localhost:5173`.
